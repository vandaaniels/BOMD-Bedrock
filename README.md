## BOMD Bedrock Public Beta 1.5.4

This is the first publicly available beta of the Bedrock Edition port.

### Included

- Night Lich
- Nether Gauntlet
- Boss combat systems
- Structures and progression
- English and Spanish localization

### Compatibility

- Minecraft Bedrock 1.26.30 or newer
- Uses @minecraft/server 2.9.0-beta

### Important

This project is still under active development. Bugs, balance problems and compatibility issues may occur.

### Installation

1. Download the `.mcaddon` file.
2. Open it with Minecraft.
3. Apply both the Behavior Pack and Resource Pack to a new world.
4. Enable the required experimental options.

### Reporting bugs

Please use the repository's Issues section and include your Minecraft version, platform, reproduction steps and Content Log errors.
